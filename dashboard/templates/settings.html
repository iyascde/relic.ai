How to Go Live
  1. 1 Copy .env.example to .env and fill in all API keys and repo details.
  2. 2 Set USE_MOCK_RESPONSES=false in .env.
  3. 3 Restart the server: docker-compose restart (or python -m webhook.server).
  4. 4 Register the GitHub webhook: Settings → Webhooks → Add webhook. Set the Payload URL to https://your-domain.com/webhook, Content type to application/json, and the secret to the value of GITHUB_WEBHOOK_SECRET. Enable events: Pull requests and Issues.
  5. 5 Create a Pinecone index named relic-ai-incidents with dimension 1536 and cosine metric.
  6. 6 Open a test PR or create an issue labeled incident to verify the full pipeline.

Danger Zone

Permanently delete all risk scores and incident records from the local database. This cannot be undone. Pinecone vector memories are not affected.
